# Semester workspace design direction

Reading this as a student planning workspace in a quiet Modernist visual language, with ENERGY 1 / RHYTHM 2 / MOTION 1.

- Color: white and near-black establish the ground; red is reserved for urgency and current time; muted course colors identify course context.
- Layout: a narrow structural sidebar keeps destinations stable while each page uses a content width suited to its information density.
- Typography: Archivo keeps controls and dense information crisp; Newsreader gives the personal greeting and voice prompt a warmer editorial voice.
- Spacing: 56px desktop margins and 44px section gaps separate decisions; 10px row spacing keeps related task data close.
- Rules: 2px rules define major regions; 1px hairlines separate repeated information without turning rows into cards.
- Elevation: shadows appear only on overlays that sit above the page.
- Motion: transitions are limited to hover and overlay entry so the workspace stays calm during study.
- Shape: controls and panels use square corners; the task checkbox is the only circular element because completion is a distinct state.

## Voice direction

Reading this as: a student planning workspace for daily study, with quiet Modernist structure and one expressive interaction, dial ENERGY 1 / RHYTHM 2 / MOTION 1.

- A small persistent island keeps Voice reachable without occupying the sidebar or page layout.
- Opening Voice reveals a bottom-center console above the functional VoiceBeam orb; the beam responds only while listening.
- Transcript, confirmation, and errors share one restrained response stage so the interaction can complete without navigating away.
- Command submission remains explicit through the Send control, with the transcript editable before execution and a persistent result shown afterwards.

## Daily briefing direction

Reading this as: a calm opening view that answers what matters today without becoming another task manager, dial ENERGY 1 / RHYTHM 2 / MOTION 1.

- Greeting: a generous Newsreader hello establishes personality while the date mark anchors the view in time.
- Priority: the next focus block and daily total appear before the chronological agenda.
- Scope: Today shows the schedule and urgent assignments only; detailed task controls remain in Assignments and Planner.
- Surface: information sits directly on the page with rules and whitespace rather than nested cards.

## V5 planning setup direction

Reading this as: a student sets the boundaries of a realistic week before the planner tries to fill it, using the same ENERGY 1 / RHYTHM 2 / MOTION 1 language.

- Structure: the setup is a four-step constraint ledger with a persistent index, strong rules, and no cards.
- Inputs: weekday and weekend planning windows protect sleep; meals and recurring commitments protect fixed personal time; preferences control focus length, buffer, and daily load.
- Integration: saved constraints appear as quiet neutral blocks in Today, Calendar, and Planner, and the Schedule action searches around them.
- Desktop behavior: the Planner becomes one column before event names become narrow enough to stack word by word.
- Honesty: Voice submits explicit event requests, and planning setup makes no claim of syncing to outside calendars.
